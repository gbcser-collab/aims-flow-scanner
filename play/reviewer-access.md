# Google Play App access / review checklist – AIMS Flow

AIMS Flow requires login. Before production submission, Play Console must receive working reviewer credentials.

Recommended dedicated review identity:
- Role: driver
- Dedicated non-production plate/account
- No access to real customer jobs or real driver data
- At least one demo job with two demo stops
- CMR/document upload enabled against a non-sensitive demo job
- Messaging enabled to a review-only/admin test conversation
- Credentials must stay valid for the entire review period

Play Console App access declaration:
- Select: All or some functionality is restricted
- Provide step-by-step login instructions
- State that no company VPN, SIM restriction or physical depot presence is required
- If a one-time code or forced code change exists, disable it for the review account or provide exact instructions

Do not place real employee credentials in Play Console.
